# Preguntas

-   Sobre dimensiones de imagen RAW (width - 4096, height - 2168, depth - 12)
-   Trabajo directamente con imágenes RAW o también imágenes RGB
-   Proceso inverso a `debayer` (si se permite trabajar cargando imágenes RGB)
-   Ejecución por defecto en CPU O GPU, quizá añadir un control (RadioButton) para seleccionarlo
-   Sobre el perfil de configuración/pipeline de operaciones:
    -   Creación interactiva de un script para posterior ejecución
        -   o
    -   Nueva vista para ejecutar un pipeline de operaciones seleccionando 1 o n imágenes y las diferentes mejoras dentro de un formulario
